3. **`backend/alembic/*` (3 files retained):**
   - `env.py`, `script.py.mako`, `versions/2026_11_22_001_initial_schema.py`.
   - Production database migration pipeline. Verified against Alembic head revision `001_initial_schema`.
4. **`database/*` (5 files retained):**
   - `schema.sql`: 33 normalized tables, foreign keys, and indexes.
   - `indexes.sql`: Multi-tenant composite lookup indexes.
